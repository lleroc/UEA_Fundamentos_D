## 📌 Descripción del Repositorio

Este repositorio reúne el material práctico desarrollado durante la materia. Los contenidos abarcan desde la lógica de programación básica hasta la resolución de problemas estructurados mediante lenguajes de programación.

### 🎯 Objetivos:
- Desarrollar el pensamiento lógico-algorítmico.
- Aplicar estructuras de control condicionales y repetitivas.
- Diseñar e implementar funciones y estructuras de datos básicas.
- Aplicar buenas prácticas de código y documentación.
